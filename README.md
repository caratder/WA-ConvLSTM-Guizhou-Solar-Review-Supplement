# Supplementary Materials for Peer-Review Responses

## Overview

This repository contains supplementary figures, tables, and validation results prepared in response to peer-review comments on the manuscript concerning grid-scale solar energy resource assessment in Guizhou Province, China, using the WA-ConvLSTM framework.

The materials are provided to facilitate transparent examination of the additional analyses and supporting evidence discussed in the authors' response letter.

## Supplementary Materials

### 1. Independent PV-Station Validation

**Figure R1-3.** Independent external analysis based on active-power observations from operating photovoltaic (PV) stations.

* Comparison of observed PV active power with ERA5-based and WA-ConvLSTM-based solar radiation estimates.
* Station-level Spearman correlation analysis across 70 PV stations.
* Supporting evidence for the discussion of external consistency and validation limitations.

### 2. Repeated-Run Performance Evaluation

**Table R1-4.** Normalized errors and skill scores for three independent runs.

* Performance comparison among TimesNet, Attention-ConvLSTM, and WA-ConvLSTM.
* Results obtained using three independent random seeds.
* Assessment of prediction-performance consistency across repeated runs.

## Purpose and Scope

These supplementary materials are provided specifically to support the responses to reviewers.

The analyses complement the revised manuscript and should be interpreted within the data sources, evaluation assumptions, and methodological limitations described in the manuscript and response letter.

## Availability

The figures and tables are organized according to the numbering used in the response letter to facilitate cross-referencing.
